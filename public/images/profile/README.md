# Operator Identity Asset Directory

Place your personal profile photo here:
`avatar.jpg` (or path `./public/images/profile/avatar.jpg`)

### Features & Behavior
- When `avatar.jpg` exists in this folder, the website automatically loads it in:
  1. The Hero section's **Operator Dossier Card** (`<OperatorPortrait />`).
  2. The Floating Optical Island **Navbar Micro-Avatar**.
- If `avatar.jpg` is not present or fails to load, the system seamlessly and automatically falls back to your live GitHub avatar: `https://github.com/yukaatsu.png`.
- Recommended format: Square or 4:5 portrait JPG/PNG, minimum 800x800px for optimal high-DPI clarity.
